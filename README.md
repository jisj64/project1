舊市尋味｜走入第二市場，從在地美食重新認識臺中

A WALK THROUGH OLD TAICHUNG：從第二市場的人情風俗，走進台中舊城的日常風景。

歡迎來到「舊市尋味」專案！本專案透過網頁視覺與城市漫遊（Citywalk）規劃，帶領大家從臺中火車站出發，走入擁有百年歷史的第二市場，探索六角樓的建築之美與在地庶民美食。

🧭 企劃亮點 (Project Highlights)

01 企劃概念 (The Idea)：以 18-24 歲年輕族群為主要目標，結合外國人視角與在地口袋名單，重新詮釋傳統市場。

02 六角樓 (History & Literature)：探索日治時期留存至今、具備放射狀六條通與監控防火功能的歷史古蹟。

03 第二市場 (Market & Daily Life)：尋訪在地古早味早餐基地與小吃集散地（如菜頭粿糯米腸、魯肉飯、紅茶等）。

04 路線規劃 (Citywalk Route)：從「臺中火車站」出發步行至「第二市場」，串聯舊城區的歷史步徑。

05 影像紀錄 (The Film)：透過影像記錄市場樣貌與在地常民生活。

06 參訪資訊 (Visit Notes)：提供實用的交通、地址與開放時間參考。

🛠️ 技術與架構 (Tech Stack)

HTML5：語意化標籤（Semantic Markup），具備無障礙設計（如跳至主要內容與 aria 屬性）。

CSS3：採多檔案模組化設計（style.css, layout.css, responsive.css），適應 RWD 手機與電腦螢幕。

JavaScript (Vanilla)：實作手機版導覽選單（Hamburger Menu）的互動展開與收合。

📂 檔案結構 (File Structure)

├── index.html        # 專案首頁
├── style.css         # 樣式表（主體外觀）
├── layout.css        # 版面配置與網格系統

└── images/           # 專案圖片與影像素材
